This program writes exactly one emoji to `entry.txt` in the output directory and then verifies the file's code points, characters, byte length, exact bytes, and that it is a single line. The heart hands emoji is a good single-emoji answer because it reads as a small, warm, wordless offer at any distance and in any language.

## How it runs

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
